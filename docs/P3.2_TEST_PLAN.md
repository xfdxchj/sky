# P3.2 Test Plan

## Data loading
1. Build and launch a 1.21.1 Fabric world.
2. Inspect logs for loaded mob and item definition counts (expected: 3 mobs, 8 items).
3. Run /skyblock mob list; expect the starter Zombie, Skeleton and Spider analogues.
4. Run /skyblock mob info private_island_zombie; verify Lv1, reference HP 100, reference Damage 20, Defense 0 placeholder, 1 coin and 5 Combat XP.
5. Run /skyblock item info training_sword; verify Damage 10, Strength 10, Crit Chance 25 and Crit Damage 50.

## Regression
1. Run /skyblock item give training_sword and /skyblock equip training_sword.
2. Run /skyblock combat; expected final stats remain Damage 10, Strength 10, Crit Chance 55 and Crit Damage 100.
3. Attack mapped mobs; confirm the existing P3.1 damage calculation remains active.
4. Kill mapped mobs; confirm rewards remain 1 coin and 5 Combat XP and persist after rejoining.
5. Attack an unregistered living entity; confirm it grants no configured rewards.
6. Verify ordinary vanilla attacks without an equipped SkyBlock weapon and PvP remain unchanged.

## Datapack checks
1. Override a mob JSON value in a test datapack, restart the world, and confirm /skyblock mob info reports the override.
2. Add malformed JSON; confirm it is logged and valid definitions still load.
3. Add an item with an unknown stat ID; confirm it is logged and skipped.

## Scope limits
- Mob HP and Damage are reference metadata only; no custom HP pool or mob AI damage yet.
- Starter mob attributes are placeholders, not verified current Hypixel values.
- Full Gradle compilation and in-game testing must be performed in the project environment before P3.2 can be marked verified.

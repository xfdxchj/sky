# P4.0 Economy and Shop Test Plan

## Build
```bash
git fetch origin
git checkout p4.0-economy-shop
gradlew build
```

## In-game setup
```text
/skyblock coins add 10000
/skyblock shop
```

## Purchase tests
- /skyblock shop buy training_sword buys one item.
- /skyblock shop buy golden_apple 3 buys a quantity.
- Confirm purse decreases by unit price × quantity.
- Confirm inventory count and used-slot count update.
- Attempt a purchase with insufficient coins; neither coins nor inventory should change.
- Fill all 36 logical inventory slots and attempt a purchase requiring another slot; coins must remain unchanged.
- Try an unknown item id and a quantity above the command maximum.

## Sale tests
- Buy or grant an item, then run /skyblock shop sell golden_apple 2.
- Confirm item count decreases and coins increase by unit price × quantity.
- Attempt to sell more than owned; neither inventory nor coins should change.
- Attempt to sell an item not listed by a shop.
- Confirm a zero sell price is rejected.

## Persistence and regression
- Save and reopen the world; coins and logical inventory must retain the transaction result.
- Confirm equip/unequip still works with purchased equipment.
- Confirm item give, coin add/remove, profile, inventory and equipment commands still work.
- Confirm no transaction changes vanilla Minecraft inventory.

## Expected limitations
The shop is command-driven and has no physical NPC or GUI. Prices are project test values, not verified Hypixel prices. Bazaar/Auction House and stock limits are not part of P4.0.

# P5.3 Hub Location Catalogue Test Plan

## Build

~~~bash
git fetch origin
git checkout main
gradlew build
~~~

A successful build must be reported from the user's local Gradle environment. This document does not claim a build has already been run for P5.3.

## Startup checks

Start a new or disposable test world and inspect the log for:

- Loaded 25 sourced Hub points of interest.
- No Failed to load Hub location data errors.
- Existing Region, Warp, NPC, Structure and Connection registries still load.

## Command checks

Run:

~~~text
/skyblock map
/skyblock hub
/skyblock hub list
/skyblock hub info village
/skyblock hub info bank
/skyblock hub info banker_npc
/skyblock hub info bazaar_alley
/skyblock hub info blacksmith_npc
/skyblock hub info graveyard
/skyblock hub info weather_station
/skyblock hub info foraging_camp
/skyblock hub locate bank
/skyblock hub nearest
~~~

Expected:
- The catalogue reports 25 points.
- /skyblock map reports the same Hub POI count.
- Each info command prints category, parent, dimension, coordinates and source URL.
- locate bank reports XYZ and distance when the player is in the Overworld.
- nearest returns up to five points in the player's current dimension, ordered by distance.

Negative checks:

~~~text
/skyblock hub info does_not_exist
/skyblock hub locate does_not_exist
~~~

Both should return a clear error without crashing.

## Safety checks

- Loading the catalogue must not generate or alter blocks.
- No NPC should spawn from an npc point record.
- No teleport should occur from locate or nearest.
- Non-Overworld dimensions should report no registered Hub points for nearest.
- The old starter fixtures and existing commands should remain available.

## Data checks

- Parse all 25 Hub location JSON files.
- Confirm all coordinates are finite.
- Confirm every record uses minecraft:overworld.
- Confirm all records have an HTTPS source URL and community_wiki provenance.
- Confirm there are no duplicate IDs.
- Confirm no unverified Region or Warp references are introduced.

## Known limitation

Coordinates are reference points copied from cited community-wiki pages. They are not full area bounds, guaranteed safe standing positions, or permission to reproduce the associated builds. Game-world geometry and exact NPC placements require separate in-game verification.

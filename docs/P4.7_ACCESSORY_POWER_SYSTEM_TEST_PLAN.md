# P4.7 Test Plan

## Build

```bash
git fetch origin
git checkout p4.7-accessory-power-system
gradlew build
```

## Accessory Power

1. Give two copies of `test_power_talisman` and put both in the Accessory Bag.
2. Confirm the line contributes stats and AP only once, while both copies occupy bag slots.
3. Create a temporary higher-rarity item with the same `accessory_line`; confirm only the higher-ranked item contributes.
4. Verify rarity AP values: Common 3, Uncommon 5, Rare 8, Epic 12, Legendary 16, Mythic 22, Divine 28, Special 3, Very Special 5, Ultimate 1, Admin 22.
5. Verify the stats multiplier at AP 0 is 0 and at positive AP follows the logarithmic formula.
6. Verify an 18-slot bag accepts 18 entries and rejects the 19th.

## Powers

1. Confirm Fortuitous and Pretty are unlocked by default.
2. Select Pretty and verify its scaled stats appear in `/skyblock stats`.
3. Give 9 `power_stone_forceful` items.
4. Run `/skyblock accessory power unlock forceful`; exactly 9 stones should be consumed.
5. Select Forceful; its stats must replace the previous Power, not stack with it.
6. Attempt to unlock Forceful with fewer than 9 stones; no items should be consumed.

## Tuning

1. Run `/skyblock accessory tuning`; available points should equal floor(AP / 10).
2. Allocate points to Crit Chance, Strength and Attack Speed.
3. Attempt to allocate more than the available total; it must fail without changing the allocation.
4. Reassign points to another stat and verify the old allocation is released.
5. Remove enough accessories to reduce AP; effective tuning must be clamped to the new available total.

## Persistence and migration

1. Select a Power and allocate tuning points, save and quit.
2. Reopen the world; selected Power, unlocked Powers and tuning allocations must persist.
3. Load a P4.6 world; it should migrate to schema 7 without losing inventory, Accessory Bag, equipment, coins, skills, quests or discovered regions.

## Regression

- Existing `/skyblock accessory add/remove/list` commands still work.
- Existing `/skyblock menu` pages still open; Accessory Bag page displays AP, selected Power and tuning summary.
- Existing combat reads final stats after Power and tuning modifiers.
- No project fixture should be described as verified Hypixel item data.

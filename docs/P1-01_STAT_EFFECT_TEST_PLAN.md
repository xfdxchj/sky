# P1-01 属性效果生命周期测试计划

> 本测试计划对应属性来源管线与持久化效果管理器。当前代码提交不代表已通过本地构建或游戏测试。

## 1. 构建与启动

- 使用 Java 21 执行 `gradlew build`。
- 创建测试世界并进入，确认没有 NBT / tick 初始化异常。
- 退出并重新进入世界，确认旧档案正常读取。

## 2. 效果应用与计算

可通过临时调试入口或后续测试命令调用 Core 内部 API：

- 应用 BUFF：`+20` Strength，持续 100 ticks；检查最终 Strength 增加 20。
- 应用 TEMPORARY：`+0.25` 的 MULTIPLICATIVE 修正；检查按现有公式乘以 1.25。
- 应用 OTHER：使用另一个 effect ID 添加同属性修正，确认不同 ID 可以并存。
- 使用同一 effect ID 再次应用，确认旧值被替换且不会重复叠加。

## 3. 移除与过期

- 主动 remove 一个效果，确认最终属性立即不再包含该效果。
- 等待持续时间到期，确认 tick 清理后效果从档案中移除。
- 检查过期前一 tick 仍有效、到期 tick 即失效。
- duration 为 0、小于 -1、非有限 amount、空 ID、空 sourceId 应拒绝。
- 尝试通过 Manager 写入 BASE / EQUIPMENT / ACCESSORY / SKILL，必须拒绝。

## 4. 存档与时钟

- 应用一个剩余时间较长的效果，保存并重启世界；确认效果保留且剩余时间按世界游戏刻推进。
- 关闭世界一段现实时间再打开，确认关闭期间效果不会因现实时间流逝而过期。
- 世界运行时玩家离线，确认 Overworld 游戏刻仍推进；玩家重新加入后到期效果被清理。
- 构造缺少 `statEffects` 的旧档案，确认按空效果列表加载。
- 构造包含未知 StatType、未知枚举、NaN/Infinity 的损坏效果条目，确认跳过该条目而不丢弃整个玩家档案。

## 5. 回归

- EQUIPMENT / ACCESSORY 来源过滤行为不变。
- 装备、Reforge、Power、Tuning 仍正常贡献属性。
- 基础属性不因效果添加或移除而被改写。
- 玩家重进后金币、技能 XP、物品、饰品、任务和区域发现数据保持不变。

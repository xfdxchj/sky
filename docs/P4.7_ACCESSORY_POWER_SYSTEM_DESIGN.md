# P4.7 — Accessory Power, Powers, Power Stones and Tuning

## Reference target

Current reference material identifies the following rules:
- Magical Power was renamed to Accessory Power in July 2026.
- Accessory Power by rarity: Common 3, Uncommon 5, Rare 8, Epic 12, Legendary 16, Mythic 22, Divine 28, Special 3, Very Special 5, Ultimate 1, Admin 22.
- Only one accessory per upgrade line contributes; the highest rarity tier takes priority.
- Selected Power stats scale by `29.97 * ln(0.0019 * AP + 1)^1.2`.
- Every 10 Accessory Power grants one base Tuning Point.
- Nine identical Power Stones unlock the corresponding Power.
- Hypixel's 0.27.3 release-candidate notes describe another 9 default bag slots and a revised Enrichment system. The project uses 18 default slots, but does not yet implement Enrichment.

Sources: Hypixel SkyBlock Wiki pages for Accessory Power, Accessories, Powers and Power Stones; Hypixel 0.27.3 release-candidate / patch notes. These are community-maintained or official forum sources as indicated in the source notes, not an official public item database.

## Implemented

- Item JSON supports `accessory_line`, `dungeon_accessory` and optional `accessory_power` override.
- Rarity enum includes the current AP tiers and values.
- Accessory Bag capacity is 18.
- Duplicate copies may be stored. Only the highest-ranked item in each accessory line contributes direct accessory stats and Accessory Power.
- Data-driven Power definitions load from `data/skyblockrpg/skyblock/powers/*.json`.
- Fortuitous and Pretty are starter powers. Forceful is a sample stone-unlocked power.
- Nine matching Power Stone items are consumed to unlock a non-starter Power.
- Exactly one selected Power contributes scaled stat modifiers; powers do not stack.
- Tuning Points are `floor(Accessory Power / 10)`. Allocations are persistent, bounded by available points, and can be reassigned.
- Tuning point values are centralized in `AccessoryPowerManager`; the current values are a provisional implementation baseline and require in-game parity validation.
- Dungeon accessory doubling is represented in the calculator API but is not connected to a dungeon runtime.
- Profile/world data schema advances to 7; old profiles receive default starter powers and empty tuning allocations.

## Commands

- `/skyblock accessory power`
- `/skyblock accessory power select <powerId>`
- `/skyblock accessory power unlock <powerId>`
- `/skyblock accessory tuning`
- `/skyblock accessory tuning set <stat> <points>`

## Test data and provenance

- `test_power_talisman.json` is project test data, not a verified Hypixel item.
- `power_stone_forceful.json` is a project fixture mapping the community-wiki Acacia Birdhouse stone to Forceful; it is not an official item data dump.
- Fortuitous, Pretty and Forceful base stat values are sourced from the community wiki and should be checked against the live target before bulk data import.

## Deferred

- Full Power Stone catalogue, recipes, unlock requirements and unique power bonuses.
- Dungeon-context AP doubling integration.
- Enrichments and their revised Tuning Point behavior from the 0.27.3 release candidate.
- Tuning templates and their unlock costs.
- Accessory Bag capacity progression beyond the current 18 default slots.
- Accessory instance metadata such as recombobulation and enrichment.

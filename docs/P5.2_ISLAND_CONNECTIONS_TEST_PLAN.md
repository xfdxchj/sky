# P5.2 Island Connections Test Plan

## Build

    git fetch origin
    git checkout p5.2-island-connections
    gradlew build

## Registry and graph

1. Start a fresh test world.
2. Run /skyblock connection list; confirm starter_bridge_fixture and starter_portal_fixture are registered.
3. Run /skyblock connection info starter_bridge_fixture.
4. Run /skyblock connection routes starter_island_spawn; confirm the starter bridge and portal point to starter_outpost_fixture.
5. Run /skyblock connection routes starter_outpost_fixture; confirm reverse adjacency is listed.
6. Confirm malformed manifests and unknown warp references are logged and skipped.

## Bridge

1. Generate the starter island fixture: /skyblock island generate starter_island_fixture.
2. Ensure the deck volume at Y=100 from X=0..30 and Z=-1..1 is empty.
3. Run /skyblock connection build starter_bridge_fixture as an operator.
4. Confirm a 3-block-wide oak-plank deck is placed and the command reports the placed block count.
5. Run it again; it must cancel because the target volume is no longer entirely air.
6. In a fresh world, place a block anywhere in the target volume before building; confirm the entire bridge build is cancelled without partial placement.
7. Test a bridge whose bounds cross world height or world border; confirm rejection.

## Portal

1. Stand near the source warp coordinate (0.5, 101, 0.5).
2. Run /skyblock connection travel starter_portal_fixture.
3. Confirm teleport to the starter outpost warp at (30.5, 101, 0.5).
4. Move more than four blocks away from the entrance and retry; travel must be rejected.
5. Confirm a portal destination with a required region remains locked until that region is discovered.

## Regression

- Run /skyblock warp list and confirm existing warps still load.
- Run /skyblock map and confirm the connection count is displayed.
- Confirm connections are not automatically built or travelled when the world loads.
- Confirm existing island generation, region discovery, warp, structure import and NPC commands still register.

## Fixture warning

All starter connection and outpost coordinates are project test fixtures, not Hypixel geometry.

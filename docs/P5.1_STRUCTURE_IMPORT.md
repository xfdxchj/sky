# P5.1 — Structure Asset Import

## Scope

P5.1 adds a manifest-driven structure placement pipeline. It uses Minecraft 1.21.1's native structure template manager and does not add WorldEdit or another runtime dependency.

Supported asset format:
- Vanilla Minecraft structure NBT (.nbt), stored at data/<namespace>/structures/<path>.nbt.
- Template identifiers use the resource identifier form, e.g. skyblockrpg:starter_marker.
- Sponge/WorldEdit .schem files are not read directly in this milestone. Convert them to vanilla structure NBT with a compatible editor/exporter before packaging.

## Manifest

Manifests live under data/skyblockrpg/skyblock/structures/*.json.

Required fields:
- id, template, dimension
- origin_x, origin_y, origin_z
- rotation: none, clockwise_90, clockwise_180, counterclockwise_90
- mirror: none, left_right, front_back

Optional fields:
- name, max_blocks (default 250000; hard maximum 4000000, enforced by the definition model)
- source, source_url, license, test_fixture

The manifest records provenance for every asset. An empty or unclear license is not permission to redistribute an asset.

## Safety rules

- Paste is an explicit operator command; loading a world never places structures.
- The target dimension must match the manifest.
- Transformed bounding box must fit inside build height and world border.
- Structure volume is capped by the manifest and by a hard upper bound.
- The entire transformed bounding box must be air before placement. If any block is occupied, the paste is cancelled before writing anything.
- Entity placement is disabled. This milestone is for static terrain/building geometry.
- The paste is server-side and uses Minecraft's native structure placement, including block-state rotation/mirror transforms.

## Commands

- /skyblock structure list
- /skyblock structure info <id>
- /skyblock structure paste <id> (permission level 2)

## Fixture

starter_marker is a tiny project-authored test fixture at (0, 200, 0). It is not Hypixel terrain. The bundled NBT fixture contains one grass block inside a 3×1×3 template volume.

## External asset research

A public SkyBlock remake repository was found with a file named private_island.schematic and a README reference to a Hub download. Its repository declares MIT, but that declaration alone does not establish the provenance or redistribution rights of the embedded Hypixel-derived map asset. Therefore the schematic is not copied into this project. Treat it as a research lead only:
- https://github.com/froggors/SkyBlock-main
- https://github.com/froggors/SkyBlock-main/blob/main/dependencies/private_island.schematic

A Hypixel community forum thread also links to older island world downloads. These are not official Hypixel map releases and their redistribution terms need separate review:
- https://hypixel.net/threads/map-downloads-for-skyblock.5915432/

# P3.5 Core Mob Content — Design

## Scope

This milestone turns the P3.4 mob catalogue into testable in-game content without pretending that every entry has full Hypixel AI or natural spawn behavior.

### Added sourced records (12)
- Spider's Den: Dasher Spider, Splitter Spider, Voracious Spider, Rain Slime, Flint Skeleton.
- The End: Enderman Lv45/Lv51/Lv59, Zealot, Zealot Bruiser, Obsidian Defender, Seer.

All records retain community-wiki provenance. Defense remains 0 only as a documented project placeholder because the cited pages do not provide a Defense stat.

## Per-instance mob identity

The previous registry resolved a mob definition only by vanilla entity type. That is insufficient when multiple SkyBlock mobs share a Minecraft entity type (for example, several Endermen or spiders).

- `entity_type` remains the fallback mapping for naturally encountered vanilla entities.
- `spawn_entity_type` selects the Minecraft stand-in used by the explicit test spawn command.
- Spawned SkyBlock mobs receive a persistent Minecraft command tag `skyblockrpg_mob_<id>`.
- `MobRegistry.get(Entity)` resolves the tag first, then falls back to the vanilla entity mapping.
- This makes custom HP, player melee Defense lookup, and incoming mob Damage use the correct per-instance definition for explicitly spawned mobs.

## Command

`/skyblock mob spawn <mobId>` (permission level 2)

- Creates the configured vanilla stand-in two blocks in front of the player.
- Sets a visible `[LvX] Name` custom name.
- Attaches the per-instance mob identity tag.
- Uses the existing P3.3 persistent SkyBlock HP pool and P3.4 incoming-damage bridge.
- It is a development/test spawn command, not a natural spawn table.

## Current limitations

- This milestone does not yet implement natural region spawning, spawn weights, biome/region detection, or Hypixel island world geometry.
- It does not yet implement unique AI such as Splitter Spider spawning Silverfish, Dasher/Voracious movement patterns, Enderman teleport/aggro rules, Zealot Special spawn rolls, Obsidian Defender Wither effect/knockback immunity, or weather-based Rain Slime conditions.
- JSON drops are catalogue data only. Actual item drop rolls and loot integration are not implemented in this milestone.
- Existing player-side vanilla armor/resistance/invulnerability handling remains in place.
- Mob Defense is not verified and remains a placeholder.
- Other vanilla entities not explicitly spawned with a SkyBlock mob tag continue to use their fallback mapping or remain unregistered.

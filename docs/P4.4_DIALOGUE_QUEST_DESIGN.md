# P4.4 Dialogue and Quest Foundation

## Scope
P4.4 extends P4.3 NPC interactions with a persistent quest loop. Dialogue remains ordered plain-text lines; quest acceptance and inspection are command-driven until the later GUI milestone.

## Quest data
Resources: `data/skyblockrpg/skyblock/quests/*.json`
- `id`, `title`, `description`
- `objective_type`: currently `talk_to_npc`
- `target_npc_id`
- `required_count`
- `reward_coins`
- optional `reward_skill` and `reward_skill_xp`

QuestRegistry validates target NPC IDs against the loaded NPC registry. Skill rewards must reference a known SkillType.

## Player state
PlayerProfile stores:
- active quest IDs and integer progress
- completed quest IDs

Both are serialized in the existing world PersistentState profile entry. Older profiles without quest lists load with empty quest state. The profile schema and world data version advance to 5; existing Purse, Bank, skills, stats, inventory and discovered regions are retained.

## Runtime flow
1. Interact with an NPC to see its configured dialogue.
2. Interacting with an NPC also advances any active `talk_to_npc` quest targeting that NPC.
3. When progress reaches the configured count, the quest is marked complete and fixed rewards are granted.
4. The starter guide uses the `quest_board` action to list quests and show their current state.

Commands:
- `/skyblock quest list`
- `/skyblock quest info <questId>`
- `/skyblock quest accept <questId>`
- `/skyblock quest abandon <questId>`

## Included test quest
`meet_the_banker` asks the player to speak with `starter_banker` once, rewarding 100 Purse coins and 25 Social XP. This is project test content, not a claim about Hypixel's actual quest text or reward values.

## Limitations
- Only one objective type exists: talk to a specific NPC.
- No branching dialogue, clickable chat options, dialogue GUI, quest chains, prerequisites, timers, daily/weekly resets, item delivery, kill objectives, region objectives or repeatable quests.
- Rewards are fixed per quest and are granted once because completed quest IDs are persisted.
- No quest tracking HUD or waypoint guidance yet.

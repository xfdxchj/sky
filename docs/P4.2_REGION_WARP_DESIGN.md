# P4.2 — Region and Warp Foundation

## Goal
Introduce a shared world-location layer that later NPC, spawn-table, collection and quest systems can query. This milestone provides region detection, first-discovery persistence and data-driven teleport destinations.

## Region model
- Regions are dimension-scoped, inclusive axis-aligned cuboids.
- Each region has an ID, display name, dimension, min/max XYZ and priority.
- If regions overlap, the highest priority wins; for equal priority, the smallest containing volume wins.
- Region definitions load from `data/skyblockrpg/skyblock/regions/*.json`.
- Server-side player tick detection announces transitions. First discovery is stored in PlayerProfile.

## Warp model
- Warp definitions include ID, display name, dimension, XYZ, yaw/pitch, optional required region ID and description.
- Warps load from `data/skyblockrpg/skyblock/warps/*.json`.
- A warp with a required region is locked until the player discovers that region.
- Destination dimension must be loaded, Y must be inside build height and the target must be inside the world border.
- Teleportation is server-authoritative.

## Persistence migration
- PlayerProfile schema advances to 4.
- Discovered region IDs are stored in the existing player profile NBT entry.
- Old profiles without `discoveredRegions` load with an empty discovery set. Existing purse, bank, skills, stats, inventory and equipment are retained.
- World data version advances to 4.

## Commands
- `/skyblock region list`
- `/skyblock region here`
- `/skyblock warp list`
- `/skyblock warp <warpId>`

## Test data warning
The included `starter_test_area` cuboid and `test_spawn` destination are project test fixtures only. They are not claimed to match Hypixel SkyBlock region boundaries, island layout or coordinates. The destination is an example coordinate in the ordinary Overworld and should be replaced when the custom island world/map is implemented.

## Out of scope
- Hypixel island terrain and map assets.
- Region polygon shapes, subregions and client-side map overlays.
- NPCs, portal entities, warp GUI, party travel and travel cooldowns.
- Region-specific natural mob spawning (future integration with the existing MobRegistry).
- Dynamic region editing commands.

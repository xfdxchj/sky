# P4.6 — Equipment, Accessory Bag and Stat Aggregation

## Goal

Extend the existing item/stat foundation into a persistent player progression layer. This milestone deliberately establishes mechanics and data contracts before importing a large Hypixel item catalogue.

## Implemented scope

- Existing weapon and armor equipment slots continue to use JSON item definitions.
- The logical inventory now has a separate, persistent Accessory Bag.
- Accessory Bag capacity is currently 9 entries as a project foundation value, not a claim about the current Hypixel upgrade progression.
- Accessories are JSON item definitions with `type: "ACCESSORY"`; they are moved from the logical inventory into the bag.
- The same accessory definition ID cannot be inserted twice. This is a definition-level duplicate guard; unique item-instance identities and accessory upgrade tiers are future work.
- Removing an accessory returns it to the logical inventory. If the inventory cannot accept it, the bag remains unchanged.
- Equipped weapon/armor and stored accessories contribute additive stat modifiers through the same aggregation path.
- Accessory Bag contents and the new profile schema version are persisted. Existing profiles without an `accessoryBag` list load as an empty bag.
- Main GUI now links to Equipment and Accessories pages. Accessory entries can be clicked to return them to inventory.
- Commands:
  - `/skyblock accessory list`
  - `/skyblock accessory add <itemId>`
  - `/skyblock accessory remove <itemId>`

## Stat calculation contract

The current `PlayerStats` pipeline remains:

1. Start with profile base stat.
2. Add all matching ADDITIVE modifiers from equipped gear and the Accessory Bag.
3. Apply MULTIPLICATIVE modifiers.
4. Apply the last OVERRIDE modifier, if present.

P4.6 adds no new multiplicative, reforge, enchantment, tuning, power-stone, set-bonus or ability calculations. Those must be added as distinct modifier sources in later milestones rather than folded into item base values.

## Data provenance

- `test_power_talisman.json` is a project test fixture only. Its stats and name are not verified Hypixel data.
- No item prices, item stats, rarity values or accessory power values are being represented as official Hypixel values in this milestone.

## Explicitly deferred

- Hypixel accessory power system, tuning points and MP-derived stat bonuses.
- Accessory bag capacity upgrades and progression unlocks.
- Unique item-instance UUIDs, recombobulation, reforges, enchantments and gemstones.
- Armor set bonuses, item abilities, weapon abilities and cooldowns.
- Equipment GUI click-to-equip/unequip; the current Equipment page is a read-only overview.
- Bazaar/Auction House acquisition and actual Hypixel item catalogue import.
- Full item-instance lore/stat formatting and rarity styling.

# P4.8 Test Plan

## Build

```bash
git fetch origin
git checkout p4.8-reforge-system
gradlew build
```

## Reforge data

1. Start a world and check the log reports two loaded reforge definitions.
2. Confirm `/skyblock reforge` lists Test Fierce and Test Titanic, each marked as a project fixture.
3. Confirm malformed or unknown-stat JSON is skipped with an error rather than crashing server startup.

## Basic roll

1. Give and equip a `training_sword` (or another reforgeable weapon fixture).
2. Run `/skyblock reforge roll weapon`.
3. Confirm 500 Purse coins are deducted and exactly one weapon reforge is stored.
4. Run the roll again; confirm it costs another 500 and replaces, rather than stacks with, the previous reforge.
5. Confirm weapon stats include the selected fixture's additive modifiers.
6. Try to roll an empty armor slot; it must fail without charging coins.
7. Equip armor and roll `helmet`, `chestplate`, `leggings` or `boots`; only the armor fixture may be selected.
8. Confirm a weapon reforge cannot be applied to an armor slot and vice versa.

## Persistence

1. Equip a weapon, apply a reforge, save and quit.
2. Reopen the world; confirm the reforge remains on that equipment slot and its stats remain active.
3. Load a P4.7 save with no reforge data; it must load with no reforges and preserve all existing inventory/profile data.

## Regression

- Existing equipment, accessory, Power, Tuning, combat and menu commands still work.
- Reforge modifiers disappear when the corresponding item is unequipped/replaced.
- Accessories do not receive reforges; their Accessory Power behavior is unchanged.
- Test fixture values must not be presented as verified Hypixel values.

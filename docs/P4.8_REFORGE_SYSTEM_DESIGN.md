# P4.8 — Reforge Foundation

## Scope

P4.8 establishes a server-authoritative, data-driven basic Reforge foundation for equipped weapons and armor. It deliberately does not combine Enchantments into this milestone.

## Reference behavior

The current community-maintained Hypixel SkyBlock Wiki describes reforges as a single replaceable modifier on eligible gear; their stats apply while the item is held or worn. Basic reforging costs 500 coins, and eligible reforges are rolled with equal probability. Accessory reforging was replaced by Accessory Powers in 0.13. See the Reforging page and the October 6, 2026 update notes.

Sources:
- https://hypixelskyblock.minecraft.wiki/w/Reforges
- https://hypixelskyblock.minecraft.wiki/w/Changelog/2026/October_6

## Implemented

- Reforge definitions load from `data/skyblockrpg/skyblock/reforges/*.json`.
- Each definition declares allowed equipment slots, coin cost, additive stat modifiers and whether it is a project test fixture.
- Basic roll selects uniformly from the compatible registered pool and charges the selected reforge's configured cost (500 coins in the included fixtures).
- A reforge is stored per equipped slot, so two different equipped items cannot share a global item-ID reforge value.
- Reapplying replaces the existing slot reforge.
- Reforge modifiers enter the same final-stat aggregation path as equipment, accessories, Powers and Tuning.
- Reforge state is stored inside PlayerInventory NBT. Old saves without the new compound load with no reforges.
- Accessories are intentionally excluded; Accessory Powers remain their current modifier system.

## Commands

- `/skyblock reforge` — list loaded reforges and costs.
- `/skyblock reforge roll <slot>` — roll a compatible basic reforge for the equipped item in that slot.

Supported slots: weapon, helmet, chestplate, leggings, boots.

## Test fixtures and limitations

- `test_fierce` and `test_titanic` are explicitly project fixtures, not verified live Hypixel reforge stat tables.
- The current data schema stores flat stat values. Rarity-scaled stat tables, item-family compatibility beyond equipment slots, mining-level requirements, first-reforge Coal, Reforge Stones, special reforge bonuses and the live Reforge Guide are deferred.
- The roll pool currently includes every loaded definition that allows the requested slot. Production data must be imported only after its live compatibility and stat tables are verified.
- The command is a development-facing service entry point; Blacksmith / The Hex / Reforge GUI interaction is not part of P4.8.

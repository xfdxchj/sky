# P5.4 — Player Private Island Foundation

## Goal

Turn the existing static island map/generator into a player-owned Private Island foundation while keeping Core as the primary mod.

This stage provides one persistent private island per player, a stable allocation, home travel, basic ownership protection and save/load. It does not yet implement the full Hypixel Private Island feature set.

## Design

### Ownership and persistence

- Private island ownership is keyed by the player's UUID.
- World-level data is stored in the Overworld PersistentState `skyblockrpg_private_islands`.
- The record stores owner UUID, dimension, center, surface height, radius, thickness, spawn coordinates and creation timestamp.
- Island placement allocation uses a deterministic grid with 512-block spacing and a monotonically increasing slot.
- The grid starts at X/Z 8192. Each island is generated at Y=270 with radius 32 and thickness 20.
- The current implementation intentionally uses the Overworld rather than adding a new dimension.
- Since VS-1 (2026-11-27), a player without an island record receives an automatically generated starter island on first join. Existing players are not forcibly teleported on subsequent joins.

### Creation

Command: `/skyblock island create`

1. Check whether the player already owns an island.
2. Reserve the next grid slot.
3. Check that the target sky volume is inside the world border and entirely clear.
4. Generate the two-island starter layout through PrivateIslandStarterLayout, using IslandManager for each terrain mass; add the starter tree, cave/chest, Jerry NPC, decorative portal and visual-only Minion pedestal.
5. Persist the ownership record only after successful generation.
6. Teleport the player to the island spawn.

If the target volume is not clear or generation fails, no ownership record is written; the blocked allocation slot is skipped so one obstruction cannot permanently stall future players. The command reports failure and can be retried.

### Home and info

- `/skyblock island home`: return to the player's own island.
- `/skyblock island private info`: show ownership, dimension, center, footprint and spawn.
- Existing static map commands (`list`, `info <id>`, `generate <id>`, `visit <id>`) remain unchanged.

### Initial protection

- Non-owners cannot break blocks inside another player's island footprint.
- Non-owners cannot interact with blocks inside another player's island or place against a protected island boundary through the standard block-interaction callback.
- The protection check uses the persisted island footprint and vertical protection range.

This is an initial protection layer, not a complete claim/security system. Explosions, pistons, fluids, entity griefing, custom item placement paths and visitor permissions require later coverage and dedicated tests.

## Boundaries

Not included in P5.4:
- Island expansion and island level.
- Visitor invitations and trusted-player permissions.
- Minions and island storage.
- Island GUI.
- Custom island dimension or void chunk generator.
- Full protection against every modded block/entity interaction path.
- Hypixel's exact Private Island terrain and structures.

## Data safety

- Existing static IslandRegistry definitions and fixtures are not modified.
- Private island records are separate from static island JSON definitions.
- Ownership uses UUID, not player name.
- Existing player profile data is not rewritten by island creation.
- A malformed private-island record is skipped without preventing other records from loading.

## Acceptance

- A player can create one private island.
- Repeating create does not generate a second island.
- Home returns to the same saved location after restart.
- Another player's island cannot be modified through tested break/interact paths.
- Existing static island generation and visit commands continue to work.
- A failed clear-volume check does not create an ownership record.

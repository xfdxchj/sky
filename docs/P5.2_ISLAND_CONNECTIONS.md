# P5.2 — Island Connections, Bridges and Portal Routes

## Scope

P5.2 adds JSON-driven map connections that link existing warp nodes. It does not invent Hypixel coordinates or replace the P5.0 island, region and warp registries.

Connection types:
- bridge: a static, operator-built walkway between two warp nodes in the same dimension.
- portal: an interaction point near a source warp that routes the player to a destination warp through the existing WarpManager.

Every connection requires source_warp_id and target_warp_id. The registry rejects missing warp references. Bridge connections additionally require both warps to use the bridge dimension.

## Bridge generation

A bridge manifest specifies start/end coordinates, odd width (1–7) and a registered block ID. The manager interpolates the centerline and deck height, then creates a flat-width walkway.

Safety:
- Explicit operator command; never generated at world startup.
- Maximum horizontal length 256 blocks and maximum width 7.
- Maximum 4,096 unique deck blocks.
- Complete preflight before placement: all target positions must be air.
- World height and world border checked for every block.
- No terrain, structures or entities are overwritten or created.

This is a simple deck bridge, not a terrain-following road, railing or support-pillar generator.

## Portal routes

Portal definitions specify an entrance coordinate and activation radius (1–16 blocks). The connection travel command only works when the player is in the entrance dimension and within the configured radius. Teleportation is delegated to WarpManager, so target-dimension checks and any target warp's discovered-region requirement remain active.

## Route graph

The connection routes command lists every bridge/portal edge connected to a warp node. This is an adjacency view, not a shortest-path planner; multi-hop route search is deferred.

## JSON location

data/skyblockrpg/skyblock/connections/*.json

Common fields:
- id, name, type, dimension
- start_x, start_y, start_z
- end_x, end_y, end_z
- source_warp_id, target_warp_id
- activation_radius, test_fixture

Bridge fields:
- width: odd integer from 1 to 7
- block_id: registered Minecraft block identifier

Portal uses the start coordinate as its entrance; end coordinates are currently reserved in the shared schema.

## Commands

- /skyblock connection list
- /skyblock connection info <id>
- /skyblock connection routes <warpId>
- /skyblock connection build <id> (permission level 2; bridge only)
- /skyblock connection travel <id> (portal only)

## Test fixtures

- starter_bridge_fixture: 3-wide oak-plank bridge from the starter island warp to a second test warp.
- starter_portal_fixture: proximity-gated test portal using the same source and destination warp pair.
- starter_outpost_fixture: test endpoint at (30.5, 102, 0.5).

All fixture data is project-authored and is not Hypixel map data. The bridge and portal should be tested in a fresh world with the P5.0 starter island fixture available.

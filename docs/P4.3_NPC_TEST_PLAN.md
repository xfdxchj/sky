# P4.3 NPC System Test Plan

Build and launch locally with Java 21 before accepting this milestone.

## 1. Registry
- [ ] Start a world and confirm the log reports 3 loaded NPC definitions.
- [ ] Confirm no invalid/duplicate NPC resource errors.
- [ ] Run `/skyblock npc list` and confirm starter_guide, starter_banker and starter_merchant appear.

## 2. Spawn
- [ ] Move inside the starter test region (for example `/tp @s 0 80 0` after confirming the P4.2 region bounds).
- [ ] Run `/skyblock npc spawn starter_guide`.
- [ ] Confirm a named, invulnerable villager appears nearby.
- [ ] Spawn banker and merchant; verify all three are independently identified even though they share the villager entity type.

## 3. Interaction
- [ ] Right-click the guide; confirm the two dialogue lines appear and no vanilla villager trade screen opens.
- [ ] Right-click the banker; confirm Purse and Bank balances appear and the existing bank commands are shown.
- [ ] Right-click the merchant; confirm the current shop catalogue and purchase command appear.
- [ ] Right-click an NPC from beyond its configured radius; confirm a too-far message and no vanilla interaction.
- [ ] Leave starter_test_area and interact again; confirm region restriction message.

## 4. Persistence and compatibility
- [ ] Save and exit, then reopen the world; confirm spawned NPC entities remain.
- [ ] Confirm P4.1 Purse/Bank balances and P4.2 discovered regions remain unchanged.
- [ ] Confirm ordinary villagers without an NPC tag still use vanilla interaction/trading.
- [ ] Confirm P3 mob interaction and combat remain unchanged.

# P5.3 Hub Location Catalogue Foundation

## Goal

Begin the current Hypixel SkyBlock Hub implementation using verifiable, version-aware location data. This increment establishes a data-driven point-of-interest catalogue and navigation queries. It does not claim to contain the Hub terrain, buildings, NPC entities, or exact region boundaries.

## Reference version and compatibility

- The location references target the post-0.24.2 Hub redesign.
- Coordinate records are sourced from the community-maintained Hypixel SkyBlock Wiki, not an official Hypixel coordinate API.
- The project currently targets Minecraft 1.21.1. The community Wiki overview reports that Hypixel SkyBlock requires Minecraft 26.1 or above as of 2026-08-18. Current-world assets must therefore be version-checked and, if legally usable, ported rather than blindly copied. See https://hypixelskyblock.minecraft.wiki/w/SkyBlock.
- Each JSON record stores its own source URL, source type and reference revision.

## Implemented

### Hub location data model

Package: com.skyrpg.skyblock.hub

- HubLocationDefinition: stable ID, display name, parent location, category, dimension, reference coordinates, description, provenance, optional Region/Warp references and fixture flag.
- HubRegistry: loads data/skyblockrpg/skyblock/hub_locations/*.json, rejects duplicate IDs, validates finite coordinates, HTTPS provenance URLs and optional Region/Warp references.
- HubCommands: list, inspect, locate and nearest-point commands.
- SkyBlockRPG: loads HubRegistry after RegionRegistry and WarpRegistry.
- /skyblock map: includes the loaded Hub POI count.

## Commands

- /skyblock hub: catalogue summary.
- /skyblock hub list: all registered points.
- /skyblock hub info <locationId>: point details and source.
- /skyblock hub locate <locationId>: coordinates and distance from the player; same-dimension only.
- /skyblock hub nearest: five nearest registered points in the player's current dimension.
- /skyblock map: includes Hub POI count alongside islands and connections.

No command in this increment teleports the player or modifies terrain.

## Map asset research and policy

Public GitHub research found older recreation projects and downloadable world references, but no current Hub asset with clearly scoped permission for redistribution in this repository:
- CarsCupcake/SkyblockRemake includes an older resources/worlds/hub.zip and an AGPL-3.0 repository license. That does not establish that third-party Hypixel-derived world assets are separately licensed for redistribution, and it is not the current Hub revision.
- SadanMasterMode/SkyblockCreation-World describes a small-scale recreation but the repository does not declare a license.
- Other recreation projects describe externally hosted world downloads without a clear asset license.

Therefore no third-party Hub world, schematic or NBT file was copied into this project. The current catalogue is metadata only. Before importing a map, record the asset's creator, source URL, exact revision, license and redistribution permission.

## Remaining P5.3 work

1. Obtain or create a Hub terrain asset with a clear right to use and redistribute it.
2. Verify the map revision and decide how to bridge the project's Minecraft 1.21.1 target with current Hypixel's newer client/world version.
3. Import the Hub terrain and buildings through P5.1 structure manifests.
4. Measure and define actual Region cuboids; do not derive region bounds from one point coordinate.
5. Add NPC placements, service bindings, Warp nodes and connection graph entries.
6. Add a safe one-time Hub installation workflow with preview/preflight and no destructive overwrite.

## Non-goals in this increment

- No procedural approximation of the whole Hub.
- No invented region boundaries.
- No NPC spawning at reference coordinates.
- No public redistribution of Hypixel map assets.
- No claim that the current map geometry is already present.

# P5.4 Private Island Test Plan

## Build

1. Pull the latest `main`.
2. Run `gradlew build`.
3. Report build output separately from in-game tests.

## First creation

1. Start a fresh test world with Core.
2. Run `/skyblock island create`.
3. Confirm the player is teleported to a floating island in the Overworld.
4. Confirm the island is near the allocated center and has a grass/dirt/stone palette.
5. Run `/skyblock island private info`; verify UUID ownership, center, radius and spawn.
6. Run `/skyblock island create` again; verify it reports the existing island and does not generate another.

## Persistence and home

1. Place a recognizable block on the island.
2. Travel away, then run `/skyblock island home`.
3. Stop the world and restart it.
4. Run `/skyblock island private info` and `/skyblock island home`.
5. Verify the same island and placed block remain.

## Protection (requires two players / LAN test)

1. Create private islands for two different UUIDs.
2. As player B, attempt to break a block on player A's island; it should be denied.
3. As player B, attempt to interact with a block on player A's island; it should be denied.
4. Attempt to place a block against the boundary of player A's island; the standard block interaction should be denied.
5. Confirm player A can break and interact with their own island.

## Failure and regression

- Verify creation fails cleanly if the target sky volume contains a non-air block.
- Verify no ownership record is created after a failed generation.
- Verify a blocked or failed slot is skipped so it cannot permanently block future allocations; no ownership record is written for the failed slot.
- Verify existing static island list/info/generate/visit commands still work.
- Verify existing Hub, warp, region, NPC, quest, profile, economy and combat features remain available.
- Note that explosions, pistons, fluids, entity griefing and non-standard modded placement paths are not covered by this initial protection layer.

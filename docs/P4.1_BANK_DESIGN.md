# P4.1 — Bank and Purse Separation

## Goal
Add a persistent Bank balance alongside the existing Purse. This is the foundation for later bank upgrades and Banker NPC/UI integration, not a claim of complete Hypixel banking behavior.

## Data and migration
- PlayerProfile stores `coins` (Purse) and `bankCoins` (Bank), both non-negative signed 64-bit integer balances.
- Existing profiles without `bankCoins` load with Bank = 0 and retain all existing data.
- Profile schema and world data versions advance to 3.
- Both balances remain in the same world-scoped PersistentState profile entry.

## Commands
- `/skyblock bank` — show Purse and Bank.
- `/skyblock bank deposit <amount>` — transfer Purse to Bank.
- `/skyblock bank withdraw <amount>` — transfer Bank to Purse.

Amounts must be positive integers. No fees, interest, capacity limits, cooldowns or upgrades are included.

## Invariants
1. Transfers validate both sides before mutating either balance.
2. Failure changes neither balance.
3. Balances remain in [0, Long.MAX_VALUE].
4. Successful transfers mark the existing world profile state dirty.
5. Shop buy/sell continues to use Purse only.

## Out of scope
Physical Banker NPC, GUI, bank upgrades, interest, account limits, profile switching, Bazaar and Auction House.

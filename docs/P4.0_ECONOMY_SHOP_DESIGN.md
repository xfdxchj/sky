# P4.0 — Economy and NPC Shop

## Goal
Connect the existing player coin balance, logical inventory, and item catalogue into a usable fixed-price shop loop. This milestone is a gameplay-system foundation, not a claim of exact Hypixel shop pricing.

## Scope
- Data-driven shop offers loaded from datapack JSON.
- One initial General Store catalogue.
- Player purchase and sale transactions using SkyBlock coins.
- Quantity support, inventory-capacity checks, insufficient-balance checks, and arithmetic-overflow guards.
- Transactions run server-side and mark world profile data dirty after success.
- Paired inventory/currency mutations are rolled back if the second operation fails.

## Data model
ShopOffer stores shop id/name, item id, buy price, and sell price. Prices are integer SkyBlock coins per item. A sell price of zero disables selling that item back.

ShopRegistry reads data/skyblockrpg/skyblock/shops/*.json. Every offer must reference an item already loaded by ItemRegistry; item ids may only be offered once in this milestone.

The included general_store.json uses project_test_values. These prices are scaffolding values and must be replaced or provenance-tagged when a sourced Hypixel shop catalogue is added.

## Commands
- /skyblock shop — list registered offers.
- /skyblock shop buy <itemId> [count] — purchase an item.
- /skyblock shop sell <itemId> [count] — sell an owned item.

The permission-gated /skyblock item give remains an administrative test command and is not part of normal shop gameplay.

## Transaction invariants
1. No coins are charged unless the full requested quantity fits in the logical inventory.
2. No item is removed unless the full requested quantity is present.
3. No sale is paid unless item removal succeeds.
4. Multiplication uses Math.multiplyExact; overflow fails without mutation.
5. Failed paired mutations restore the earlier mutation.
6. Successful transactions mark the world-scoped profile state dirty exactly once.

## Out of scope
- Physical NPC entities and interaction UI.
- Shop categories, rotating stock, NPC location restrictions, taxes, buy limits, and reputation requirements.
- Bazaar, Auction House, player-to-player trading, bank accounts, and purse/bank split.
- Vanilla item-stack rendering; this continues to use the existing logical SkyBlock inventory.
- Hypixel-accurate prices until each offer has a reliable source and timestamp.

## Verification status
Implementation is committed to the feature branch. A local Java 21 Gradle build and in-game tests are still required; do not treat this document as evidence of runtime verification.

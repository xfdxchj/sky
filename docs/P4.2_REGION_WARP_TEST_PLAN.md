# P4.2 Test Plan — Region and Warp

## Build
- [ ] Run `gradlew build` with Java 21.
- [ ] Confirm resource JSON files load without registry errors.

## Region detection
- [ ] `/skyblock region list` includes `starter_test_area`.
- [ ] Stand inside its cuboid and run `/skyblock region here`; expect Starter Test Area.
- [ ] First entry displays a discovery notification.
- [ ] Leave the cuboid and re-enter; region notification appears again but it is not marked as a first discovery.
- [ ] Stand outside all configured cuboids; `region here` reports Unassigned.
- [ ] Add overlapping test regions with different priorities; highest priority wins.
- [ ] For equal priorities, smaller region wins.

## Warp behavior
- [ ] `/skyblock warp list` shows `test_spawn` as locked before discovering the region.
- [ ] Discover `starter_test_area`; warp becomes unlocked.
- [ ] `/skyblock warp test_spawn` teleports to the configured Overworld coordinates.
- [ ] Unknown warp IDs fail without teleporting.
- [ ] A warp referencing an unloaded dimension fails cleanly.
- [ ] Out-of-build-height and outside-world-border destinations are rejected.

## Persistence and migration
- [ ] Discover the region, save and close the world, then reopen.
- [ ] `/skyblock warp list` still shows the region-gated warp as unlocked.
- [ ] Existing P4.1 profile without `discoveredRegions` loads with no regions discovered.
- [ ] Verify Purse, Bank, skills, stats, inventory and equipment remain intact.

## Regression

- [ ] Existing mob and combat commands remain available.

# P3.2 Data Schema

P3.2 moves the current starter catalogue into standard Minecraft datapack resources.

- Mob JSON: data/skyblockrpg/skyblock/mobs/<file>.json
- Item JSON: data/skyblockrpg/skyblock/items/<file>.json

## Mob fields

| Field | Type | Meaning |
|---|---|---|
| id | string | Stable internal SkyBlock mob ID |
| name | string | Display name |
| entity_type | string | Optional vanilla entity type mapping |
| level | integer | SkyBlock level |
| health | number | Reference SkyBlock HP |
| damage | number | Reference SkyBlock damage |
| defense | number | Defense used by the current player damage calculation |
| coin_reward | integer | Coins awarded on kill |
| combat_xp_reward | number | Combat XP awarded on kill |
| source_type | string | official-api, community-wiki, project-placeholder, etc. |
| source_url | string | Source URL |
| retrieved_at | string | Research snapshot date |
| confidence | string | Provenance and caveats |

Unknown or unverified values must not be presented as official. The starter Zombie and Skeleton rows use community-wiki listed values. Spider uses minimum-range values pending exact lowest-tier row verification. Defense 0 is an explicit project placeholder for all three vanilla analogues. These are not official API records.

## Item fields

| Field | Type | Meaning |
|---|---|---|
| id, name | string | Stable ID and display name |
| rarity | enum string | COMMON, UNCOMMON, RARE, EPIC, LEGENDARY, MYTHIC |
| type | enum string | WEAPON, ARMOR, ACCESSORY, MATERIAL, CONSUMABLE |
| equipment_slot | string | Optional equipment slot |
| max_stack_size | integer | Maximum logical stack size |
| stats | object | StatType ID to numeric value |
| lore | string array | Display lore |

## Runtime behavior

Registries load when the server starts from the active ResourceManager. Invalid individual files are logged and skipped. The registry contains valid definitions found in the active resource set. Mob reference HP and Damage are metadata only in this milestone: they do not change vanilla entity max health or implement mob attack AI. Vanilla entity type mapping remains a temporary bridge until custom SkyBlock mob entities are implemented.

# P4.4 Dialogue and Quest Test Plan

Build and launch with Java 21 before accepting this milestone.

## 1. Registry and commands
- [ ] Startup log reports 3 NPC definitions and 1 quest definition.
- [ ] `/skyblock npc list` shows starter_guide, starter_banker and starter_merchant.
- [ ] `/skyblock quest list` shows meet_the_banker as Not accepted.
- [ ] `/skyblock quest info meet_the_banker` shows target NPC, count and rewards.

## 2. Quest flow
- [ ] Spawn and interact with starter_guide; its dialogue and quest board are shown.
- [ ] Accept with `/skyblock quest accept meet_the_banker`.
- [ ] `/skyblock quest list` reports In progress: 0/1.
- [ ] Spawn and interact with starter_banker inside starter_test_area.
- [ ] Confirm quest completion, +100 Purse coins and +25 Social XP.
- [ ] Confirm quest list reports Completed.
- [ ] Interact with starter_banker again; confirm no duplicate reward.
- [ ] Attempt to accept the completed quest again; confirm it is rejected.
- [ ] Abandon an active quest and confirm it returns to Not accepted.

## 3. Persistence and migration
- [ ] Save and exit while a quest is active at progress 0; reopen and confirm it remains active.
- [ ] Complete the quest, save and reopen; confirm completed status persists.
- [ ] Verify existing Purse, Bank, skills, stats, inventory and discovered regions remain unchanged after schema version 5 migration.

## 4. Compatibility
- [ ] Interacting with non-target NPCs does not advance the quest.
- [ ] Interacting outside an NPC's required region does not advance the quest.
- [ ] Ordinary untagged villagers still use vanilla interaction.
- [ ] Existing bank, shop, warp, mob and combat commands continue to work.

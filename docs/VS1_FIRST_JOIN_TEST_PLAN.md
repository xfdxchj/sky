# VS-1 首次进入与私人岛测试计划

> 目标：验证新玩家首次加入时自动创建私人岛并传送；验证重连行为与失败边界。
> 版本：Minecraft 1.21.1 / Fabric / Java 21。
> 当前实现状态：源码已提交，以下项目尚未由本地执行结果证明。

## A. 构建与启动

1. 在最新 main 执行 `.gradlew.bat build`。
2. 启动 Core-only 的 `runClient`。
3. 创建全新单人世界，确认服务端无初始化异常。

## B. 首次加入

1. 使用全新世界/新玩家 UUID 进入。
2. 预期：自动创建玩家档案与私人岛记录。
3. 预期：玩家被传送到 Overworld 天空网格中的私人岛出生点（当前首版坐标分配从 X/Z=8192 开始）。
4. 预期：玩家收到 Private Island 已准备完成的提示。
5. 检查岛屿表面与底部是否生成；玩家不应出生在虚空或岛屿内部。
6. 检查服务端日志出现首次私人岛创建记录。

## C. 重连与回家

1. 退出世界并重新进入。
2. 预期：不再生成第二座岛，不改变私人岛所有者记录。
3. 预期：已有岛屿玩家不会被强制传送，保留退出前所在位置。
4. 执行 `/skyblock island home`，确认可以返回私人岛。

## D. 隔离与失败边界

1. 在另一名玩家的私人岛尝试破坏/放置方块，确认现有保护逻辑仍生效。
2. 在预留天空区域放置阻挡方块后，使用新玩家首次加入，确认空域预检失败时不会创建错误的所有权记录。
3. 检查失败时玩家收到提示，服务端记录明确原因。
4. 检查已有世界地形未被自动生成流程覆盖。

## E. 已知限制

- 当前生成的是项目自有单一椭圆浮岛 fixture，不是 Hypixel 原始地图。
- 尚未生成 Hypixel Wiki 所描述的第二座副岛、橡树、洞穴、初始箱子、Jerry、Hub Portal 和 Cobblestone Minion I。
- 尚未验证维度边界、区块加载、重启持久化和多人并发首次加入。
- 自动创建会在 JOIN 事件中执行当前同步的岛屿生成循环；需在游戏内观察首次生成耗时。

## 通过标准

A-D 全部通过，且没有重复分配、错误传送、方块覆盖或所有权记录异常。完成后再进入双岛结构还原与起始 NPC/物资生成。


## F. 双岛布局与初始内容（本轮新增）

1. 使用一个全新玩家 UUID 首次加入，确认主岛与副岛均生成，且两岛没有被地形意外切断或大面积重叠。
2. 确认玩家出生在带橡树的主岛，不在树叶/方块内部，跳跃和移动空间正常。
3. 前往副岛，确认洞穴入口可进入，洞穴内部有火把和箱子。
4. 打开箱子，核对：熔岩桶×1、水桶×1、骨粉×3、泥土×5、草方块×7、圆石×8。
5. 与 Jerry 交互，确认出现 Jerry 的 NPC 对话；确认 Jerry 不会走动或被普通攻击杀死。
6. 确认 Hub Portal 目前只是装饰，不应误认为已能传送；Minion 底座目前也只是展示，不应产生资源。
7. 在主岛、副岛和两岛之间测试非所有者保护；确认岛屿边缘外的正常世界区域不被误保护。
8. 退出并重进，确认不重复生成第二套岛屿、箱子或 Jerry；箱子已取走的物品不应被重新补发。

注意：当前两岛和洞穴均为程序生成的项目自有布局，并非从 Hypixel 世界文件导入。

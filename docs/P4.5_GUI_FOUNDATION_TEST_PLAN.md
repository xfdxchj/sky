# P4.5 GUI Foundation Test Plan

Run on Java 21 with Minecraft 1.21.1 and Fabric.

## Build and launch
- [ ] `gradlew build` completes.
- [ ] Client starts without ScreenHandlerType registration errors.
- [ ] Integrated singleplayer world starts and loads existing player profile.

## Main menu and navigation
- [ ] Run `/skyblock menu`; a custom SkyBlock menu opens.
- [ ] Main menu shows Profile, Bank, Quests and Shop.
- [ ] Click Profile; player name and Purse display.
- [ ] Click Back; main menu returns.
- [ ] Click Bank; Purse and Bank balances match `/skyblock bank`.
- [ ] Click Quests; quest entries show accurate accepted/completed state.
- [ ] Click an unaccepted quest; it becomes active and the list refreshes.
- [ ] Click Shop; registered shop offers are listed.

## Slot safety
- [ ] Clicking menu icons does not move them into the player inventory.
- [ ] Shift-click, right-click and number-key interactions do not extract or insert menu icons.
- [ ] Closing the menu does not alter player inventory or profile data.

## Multiplayer isolation / state
- [ ] If testing with two players on an integrated/LAN world, one player's quest actions do not affect the other player's menu actions.
- [ ] Close and reopen each menu repeatedly; no stale click mapping remains.

## Regression
- [ ] Existing `/skyblock quest`, `bank`, `shop`, `npc`, `warp` and profile commands still work.
- [ ] Save and reopen the world; existing profile and quest data remain intact.

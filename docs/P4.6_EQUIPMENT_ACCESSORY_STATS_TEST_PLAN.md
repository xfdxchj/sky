# P4.6 Test Plan

Run with Java 21 from the project root.

## Build

```bash
gradlew build
```

## Accessory inventory flow

1. Start a world and run `/skyblock item give test_power_talisman`.
2. Run `/skyblock inventory`; confirm the talisman is in the logical inventory.
3. Run `/skyblock accessory list`; confirm the bag is empty and capacity is shown as 0/9.
4. Run `/skyblock accessory add test_power_talisman`.
5. Confirm the item is removed from logical inventory and appears in `/skyblock accessory list`.
6. Run `/skyblock stats`; confirm Strength increases by 5 and Health by 10.
7. Attempt to add the same accessory again; it must fail without changing inventory or bag.
8. Run `/skyblock accessory remove test_power_talisman`; confirm it returns to inventory and its stats are no longer applied.

## Persistence and migration

1. Add an accessory, save and quit.
2. Reopen the same world; confirm the accessory remains in the bag and its stats remain applied.
3. Load a world/profile created before P4.6; it should load with an empty Accessory Bag and preserve existing items, equipment, stats, coins, skills, quests and discovered regions.

## GUI

1. Run `/skyblock menu`.
2. Open Equipment and verify the five equipment slots are displayed.
3. Open Accessories and verify bag capacity and current entries.
4. Click an accessory; it should return to inventory and disappear from the page.
5. With the logical inventory full, attempt removal by command and GUI; it must fail without deleting the accessory.
6. Test right-click, shift-click and number-key interactions; menu icons must not move into the player's inventory.

## Regression

- Existing `/skyblock equip <itemId>` and `/skyblock unequip <slot>` behavior remains available.
- Existing weapon damage still reads final Damage, Strength, Crit Chance and Crit Damage values.
- Bank, shop, quest and warp data must remain unchanged.
- No accessory fixture should be described as an official Hypixel item.

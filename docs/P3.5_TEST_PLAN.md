# P3.5 Core Mob Content — Test Plan

## Build

Run with Java 21:

```bash
gradlew build
```

Build and runtime verification are pending in the project owner's local environment.

## Data loading

After entering a world, run:

```text
/skyblock mob list
```

Expected total: **70 definitions** (58 previous + 12 added), assuming all existing P3.4 records remain valid.

Verify these records:

```text
/skyblock mob info dasher_spider
/skyblock mob info splitter_spider
/skyblock mob info voracious_spider
/skyblock mob info rain_slime
/skyblock mob info flint_skeleton
/skyblock mob info enderman_45
/skyblock mob info enderman_51
/skyblock mob info enderman_59
/skyblock mob info zealot
/skyblock mob info zealot_bruiser
/skyblock mob info obsidian_defender
/skyblock mob info seer
```

Confirm each reports its area, family, spawn entity type, sourced stats, drop count and source URL.

## Explicit spawn and per-instance identity

As an operator, test both newly imported records and the existing level variants:

```text
/skyblock mob spawn zombie_15
/skyblock mob spawn skeleton_14
/skyblock mob spawn spider_15
/skyblock mob spawn crypt_ghoul
/skyblock mob spawn pack_spirit
/skyblock mob spawn dasher_spider
/skyblock mob spawn enderman_45
/skyblock mob spawn enderman_59
/skyblock mob spawn zealot
/skyblock mob spawn zealot_bruiser
/skyblock mob spawn obsidian_defender
```

Verify:
- A vanilla stand-in appears two blocks in front of the player.
- The visible name includes the correct SkyBlock level and name.
- Two different Enderman definitions can coexist and retain separate per-entity identity.
- The spawned entity uses the configured SkyBlock HP, not only vanilla max HP.
- Player attacks with a registered SkyBlock weapon display the correct mob name and HP pool.
- Incoming melee damage from a tagged mob uses its configured SkyBlock Damage.
- A projectile fired by a tagged skeleton/other projectile-capable mob resolves its owner definition where applicable.
- Untagged vanilla entities retain the previous fallback behavior.

## Regression

- P3.1 weapon damage and crit calculations still work.
- P3.3 persistent HP pools survive save/reload.
- P3.4 incoming mob damage still preserves vanilla player mitigation.
- Unregistered entities do not gain SkyBlock kill rewards.
- PvP and environmental damage are unchanged.
- `/skyblock mob list`, `/skyblock mob info`, item commands and profile persistence still work.

## Not covered

Natural spawning, drops being granted, special AI/abilities, regional world generation, and Bestiary progression are not part of this test milestone.

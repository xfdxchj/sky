# P5.1 Structure Import Test Plan

## Build

    git fetch origin
    git checkout p5.1-structure-import
    gradlew build

## Manifest loading

1. Start a fresh test world.
2. Run /skyblock structure list; confirm starter_marker is registered.
3. Run /skyblock structure info starter_marker; confirm template, dimension, origin, rotation, mirror and provenance are displayed.
4. Confirm malformed manifests and invalid enum values are logged and skipped.

## Structure placement

1. Ensure the Overworld target at (0, 200, 0) is empty.
2. Run /skyblock structure paste starter_marker as an operator.
3. Confirm exactly one grass block appears at (1, 200, 1), relative to the manifest origin at (0, 200, 0).
4. Run the paste command again; it must cancel because the target bounding box is no longer entirely air.
5. Put any block inside the 3×1×3 target box and confirm paste is cancelled without changing any other block.
6. Change a local test manifest to a different rotation and mirror, then verify the transformed bounding box and block state orientation.
7. Confirm a mismatched dimension, out-of-height placement, border crossing, missing template and over-limit volume are rejected.

## Regression

- Existing island, region, warp, NPC, quest, GUI, economy, equipment, accessory, reforge and combat commands still register.
- Opening an existing world does not paste structures automatically.
- The fixture remains clearly labelled as project test content and is not represented as Hypixel geometry.
